# واجهة التنبؤ باستهلاك الطاقة

هذا الملف يضيف واجهة Streamlit إلى مشروع التحليل الأصلي دون تغيير خلايا الدفتر الأصلي.

## التشغيل
1. فك ضغط الحزمة.
2. افتح الطرفية في مجلد المشروع.
3. ثبّت المتطلبات: `pip install -r requirements.txt`
4. شغّل الواجهة: `streamlit run app.py`

ملف `energy_model.joblib` مدرّب بالفعل بنفس إعدادات Random Forest الموجودة في الدفتر الأصلي. عند الحاجة لإعادة تدريبه، شغّل `python train_and_export.py`.

## تنبيه
- يجب إدخال جميع قراءات الحساسات المتوافقة مع بيانات التدريب، أو استخدام القيم الافتراضية للعرض التوضيحي فقط.
- بيانات المصدر تخص منزلًا واحدًا فقط، والتقييم الحالي عشوائي وليس اختبارًا زمنيًا مستقبليًا.
- التوقع بوحدة Wh لكل 10 دقائق وليس استهلاك المنزل بالكامل.
