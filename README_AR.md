# التنبؤ باستهلاك الطاقة ⚡

مشروع تعلّم آلة للتنبؤ باستهلاك طاقة الأجهزة المنزلية بوحدة واط-ساعة لكل عشر دقائق، باستخدام بيانات UCI المجمعة من **منزل واحد**.

## تنظيم الملفات
- `data/`: البيانات الأصلية.
- `notebooks/`: دفتر التحليل: استكشاف البيانات وهندسة الخصائص ومقارنة خمسة نماذج انحدار.
- `src/`: هندسة الخصائص المشتركة وتدريب نموذج Extra Trees.
- `models/`: النموذج المدرّب والمحفوظ.
- `app/`: واجهة Streamlit التفاعلية.
- `reports/`: نتائج التقييم العشوائي والزمني.

## التشغيل من داخل المجلد الرئيسي
```bash
python -m pip install -r requirements.txt
python src/train_and_export.py
python -m streamlit run app/app.py
```

## ملاحظات مهمة
- استخدمنا التمثيل الدوري للساعة واليوم بدل الاحتفاظ بالساعة واليوم الخام في مدخلات النموذج.
- النموذج المحفوظ هو Extra Trees؛ وواجهة التطبيق تستخدم هندسة الخصائص نفسها المستخدمة في التدريب.
- النتائج العشوائية والزمنية موثقة في `reports/` ويجب عدم الخلط بينها.
- القيم الافتراضية للحساسات ليست قراءات حية؛ ولا يصح تعميم النموذج على جميع المنازل.

## التقرير النهائي والتوصيات المحدّثة
راجع [`reports/FINAL_REPORT_AR.md`](reports/FINAL_REPORT_AR.md) للتقييمين العشوائي والزمني، والقيود والتوصيات وملخص الأسطر الخمسة. الاختبار الزمني **أُجري بالفعل** وكانت نتيجته ضعيفة؛ لذلك الأولوية لتحسين التعميم المستقبلي، وليس مجرد إجراء الاختبار. ملف `reports/README_AR_legacy_archive.md` أرشيف للنسخة القديمة ولا يمثل التعليمات الحالية.
